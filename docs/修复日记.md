# Reynard 0.10.1 修复日记

本次更新合并了上游 0.10.1 的文件上传与物理键盘修复，并继续处理输入、浏览、CPU 和内存使用的稳定性问题。发布包会在生成后进行完整性检查，确保安装文件可以正常使用。

## 关闭键盘交互

现在，当软件键盘出现时，屏幕左下方、紧贴键盘上沿会显示 **“关闭键盘”** 按钮。点击后键盘会立即向下收起，当前网页不会重新加载，也不会切换标签页。正在编辑的文字与页面选择状态会保留，方便在输入和查看网页内容之间快速切换。

同时保留了设置中的“双指长按关闭键盘”选项。无论使用点击按钮还是双指长按，网页滚动和普通触控不会被取消。

## 苹果原生输入与手写

针对苹果原生中文手写及系统文本输入期间出现的断触问题，浏览器会在键盘即将出现时优先暂停网页返回、全屏返回和下拉刷新等导航手势；键盘收起后再恢复相应手势。这样可以避免浏览器手势抢占手写笔画，让连续书写和光标编辑更加稳定。

## 搜索与浏览设置

搜索引擎中加入了百度、头条、360、搜狗、夸克与谷歌、必应等预设，并支持常用快捷词。浏览设置提供了网页手势返回模式、下拉刷新、滑动进入全屏、双指长按关闭键盘、启动时恢复上次页面或打开指定网页等选项。兼容性设置中也可选择默认浏览器标识或 Android 兼容标识。

## CPU、进程与内存优化

应用在失去前台焦点时会立即暂停非画中画网页会话的活动状态，以降低后台网页脚本、渲染和网络任务带来的 CPU 消耗；返回前台后会直接恢复既有会话，而不是重新创建标签进程。正在使用画中画的会话保持可用，不会被这项优化中断。

当系统发出内存告急通知时，浏览器会优先释放标签总览缩略图和历史导航预览图。这些图像均可在需要时重新生成，因此不会关闭标签、删除网页历史、清空输入内容或丢失页面状态。

## 构建与缓存

引擎构建产物和应用层依赖使用独立缓存。日常的界面、设置、文档或 Swift 修复会直接复用已验证的 Gecko 引擎产物；只有引擎版本、补丁或引擎构建脚本改变时，才会重新编译引擎。每次发布仍会生成新的 TrollStore 安装包并执行 ZIP 结构和 SHA-256 校验。

## 本次修正

| 项目 | 修改内容 |
|---|---|
| 键盘关闭 | 新增贴靠键盘上沿的点击式“关闭键盘”按钮，并保留双指长按方式。 |
| 手写断触 | 在系统输入生命周期内暂停会抢占触控的网页导航与刷新手势。 |
| 手势稳定性 | 修正全屏网页返回手势的类型处理，避免影响边缘返回动画，并合并物理键盘快捷键修复。 |
| 文件上传 | 合并上游文件选择器完成状态修复，改善网页上传文件后的选择器关闭行为。 |
| 后台 CPU | 场景失焦时暂停非画中画网页会话；重新激活时复用现有会话。 |
| 内存回收 | 内存告急时清理可重建的标签与历史预览图，不影响标签、历史和网页状态。 |
| 构建可靠性 | 保持 Gecko 与应用层依赖分层缓存；安装包在发布前完成 ZIP 结构和 SHA-256 校验。 |

> 如遇到网页本身的输入框兼容问题，可先点击“关闭键盘”查看页面内容，再点选输入框继续编辑；浏览器会保持当前页面和文字输入状态。

感谢反馈。后续更新会继续优先处理影响输入、下载、播放和网页兼容性的实际使用问题。
